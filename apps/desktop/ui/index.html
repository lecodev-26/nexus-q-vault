THE PROBLEM

Tu información merece algo más que confiar en una carpeta.

Un dispositivo puede perderse, compartirse o quedar expuesto. Los documentos sensibles suelen acabar mezclados con archivos cotidianos, sin una capa clara de protección ni una forma ordenada de recuperar el acceso.

◈

Protección local

Cifra archivos y carpetas desde tu equipo. El trabajo criptográfico se realiza en la aplicación; tus originales permanecen intactos.

▤

⌁

Control transparente

VAULT DESBLOQUEADO

Operaciones seguras

Cifrar archivo

El archivo cifrado se crea junto al original con extensión .nqx.

Restaurar archivo

El destino debe ser nuevo; nunca se sobrescribe silenciosamente.

Cifrar carpeta

Los nombres y las rutas se guardan en un manifiesto cifrado. No modifica los originales.

Se propone un nombre dentro de la carpeta elegida; puedes editar la ruta.

Restaurar carpeta

La carpeta de destino debe ser nueva. Se validan el manifiesto y cada objeto cifrado.

Se propone una carpeta nueva dentro de la ubicación elegida.

Crear backup

Protege el contenedor y sus claves; no incluye los archivos .nqx ni las carpetas protegidas.

Restaurar backup

Restaura las claves en un vault nuevo. Los archivos cifrados se conservan aparte.

Automatic vault lock

Lock the vault after a period without keyboard or pointer activity. This setting stays on this device.

The countdown is enforced by the Rust backend. Closing the app also locks the vault. Desktop operating systems do not expose a portable screen-lock or suspend event through Tauri.

GETTING STARTED

Help & user guide

01

Create your vault

Choose a location, create a strong unique password and keep it safe. The vault file stores your protected key material.

02

Unlock your vault

Select your existing .nqv file and enter its password. Lock the vault whenever you leave your computer.

03

Protect files and folders

Unlock first, then choose a file or folder to encrypt. Original files are not deleted automatically.

04

Make a recovery backup

Create an encrypted .nqb backup with a separate strong passphrase. Store it separately from your encrypted files.

05

Restore safely

Use the backup passphrase to restore into a new vault. Keep the encrypted .nqx files and folder-vault data separately.

06

Important limitations

Folder encryption currently supports files up to 32 MiB, skips empty folders and rejects symbolic links. This early-access release has not been independently audited.
