Crear backup de claves del vault

El archivo .nqb protege el estado del vault y sus claves; no es una copia de tus documentos.

Qué guarda este backup
  • Incluye: El estado cifrado del vault y el material de claves necesario para recuperarlo.
  • No incluye: Archivos .nqx, manifiestos manifest.nqm ni objetos de carpetas cifradas.

Conserva por separado el .nqb y copias de todos tus archivos .nqx y carpetas cifradas. La contraseña del backup es independiente de la contraseña del vault; guárdala aparte del archivo.

Restaurar backup de claves

Importa el estado del vault desde un .nqb y crea un vault nuevo.

Antes de restaurar: necesitas estos dos componentes de recuperación
  • El backup de claves del vault (.nqb) y su contraseña independiente.
  • Los documentos cifrados conservados por separado: archivos .nqx y datos de carpetas cifradas.
  1. Importa el .nqb con su contraseña independiente y crea un vault nuevo con una contraseña nueva.
  2. Una vez creado el vault, utiliza las claves restauradas para descifrar los archivos .nqx y restaurar los datos de las carpetas cifradas conservadas por separado.

El .nqb no contiene documentos cifrados y no revela, recupera ni restablece la contraseña original del vault. Sin el backup .nqb, su contraseña independiente y los documentos cifrados conservados por separado, la recuperación puede ser imposible.

Automatic vault lock

Lock the vault after a period without keyboard or pointer activity. This setting stays on this device.

The countdown is enforced by the Rust backend. Closing the app also locks the vault. Desktop operating systems do not expose a portable screen-lock or suspend event through Tauri.

GETTING STARTED

Help & user guide

01

Create your vault

Choose a location, create a strong unique password and keep it safe. The vault file stores your protected key material.

02

Unlock your vault

Select your existing .nqv file and enter its password. Lock the vault whenever you leave your computer.

03

Protect files and folders

Unlock first, then choose a file or folder to encrypt. Original files are not deleted automatically.

04

Make a vault-key backup

The encrypted .nqb stores vault/key state only. It excludes .nqx files, folder manifests and encrypted folder objects. Keep all encrypted documents separately and store the backup passphrase away from the .nqb file.

05

Restore keys and documents

Import the .nqb with its separate backup passphrase and create a new vault with a new vault password. The restored keys are then used to decrypt your separately preserved .nqx files and restore your encrypted folder data. This does not reveal or reset the original vault password.

06

Important limitations

Folder encryption currently supports files up to 32 MiB, skips empty folders and rejects symbolic links. This early-access release has not been independently audited.

Share files with a recipient

Create a receiving identity, export its public .nqcontact card and verify the full fingerprint with the recipient through a separate trusted channel. Share the .nqx package through any channel. Decryption does not authenticate the sender; keep a separate .nqb backup of your receiving keys.
